#### 1.4.6.2 获取 HTTP-FLV 取流地址

```text
名称           内容
Path         /vms/open/httpFlvService/v1/getHttpFlvUrl
请求参数
             【可选】设备的17位设备码，设备标签上或扫描设备二维码得到的字符串，取
qrCode       该字符串"TP*"的后17位字符，即第4位到第20位字符（从1开始计数）。例如：
string       设备标签或扫描二维码得到的字符串为：TP116E0091709B04C926B00，这里取
             "16E0091709B04C926"。
             mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode
             为准。

mac          【可选】设备mac地址，格式如00-FF-00-17-00-18，字母大写并用"-"分隔
string       mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode
             为准。

channelId    【必选】视频类设备独有字段，子设备的通道编号，存在以下几种情况：
int          1. IPC直接绑定商云账号，此字段固定为1
             2. 多目IPC直接绑定商云账号，代表目标摄像头的编号，从1开始
             3. NVR绑定商云账号，IPC通过添加为NVR通道接入商云，代表目标通道的

                   编号，从1开始

type         【必选】流类型，枚举类型

                   sdvod   回放

int                【注意】编码改变该设备下所有拉流编码都会改变
使用限制
功能说明               枚举值 含义

                   H264    H264编码

                   H265    H265编码

                   【可选】回放开始时间，毫秒级时间戳，只对回放有效，type 为 sdvod 时，该

                   【可选】回放结束时间，毫秒级时间戳，只对回放有效

                   url     HTTP-FLV 取流地址，有效期为 2h，一个地址同时只能拉一路
```
