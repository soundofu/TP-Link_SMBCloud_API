##### 1.4.4.1.1 获取 IPC/NVR 设备校时方式

```text
名称          内容

Path        /vms/open/deviceConfig/v1/getDeviceTimingInfo
请求参数

qrCode      【可选】设备的17位设备码，设备标签上或扫描设备二维码得到的字符串，取该字
string      符串"TP*"的后17位字符，即第4位到第20位字符（从1开始计数）。例如：设备标签
            或 扫 描 二 维 码 得 到 的 字 符 串 为 ： TP116E0091709B04C926B00 ， 这 里 取
mac         "16E0091709B04C926"。
string      mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为准。

channelId   【可选】设备mac地址，格式如00-FF-00-17-00-18，字母大写并用"-"分隔
int         mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为准。

回复参数        【可选】视频类设备独有字段，子设备的通道编号，存在以下几种情况：
            1. IPC直接绑定商云账号，此字段固定为1
            2. NVR绑定商云账号，IPC通过添加为NVR通道接入商云，代表目标通道的编号，

                 从1开始

error_code  错误码，0代表正常，其他值参考常用错误码说明
int

                                   设备校时方式，枚举类型

result  timingMode                 枚举值     含义
object  string                     manual  手动校时
                                   ntp     ntp自动校时
使用限制
功能说明    serverIp                   NTP服务器地址，该字段配合自动校时使用
        string

        1. 设备型应用和项目型应用均可调用
        2. 需要目标设备处于试用中或付费使用中状态方可调用

        查看设备校时信息

示例：
Request:
{

      "qrCode": "16E0091709B04C926",
      "channelId": 1
}

Response:
{

      "error_code": 0,
      "result":
      {

            "timingMode": "ntp",
            "serverIp": "0.0.0.0"
      }
}
```
