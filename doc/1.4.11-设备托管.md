#### 1.4.11.2 设置托管回调配置

```text
名称               内容

Path             /tums/open/deviceEntrust/v1/setEntrustDeviceCallbackConfig

请求参数

                 【必选】回调开关，是否需要商云后台触发回调

enableCallback   枚举值  含义
int              0    回调关闭

                 1    回调开启

callbackAddress  【可选】回调地址，回调开关为1时必填，长度限制：[1, 1024]
string           形如：http[s]://{domain}/{url}
                 注：配置时商云后台会主动触发一次该回调地址，以校验地址合法性，该校验
                 请求的请求体为空json字符串"{}"，需响应{"error_code":0}用于通过校验，否则
                 接口返回-82400

secretKey        【可选】HmacSHA256算法加密密钥，长度限制：[0, 32]
string           不为空时，商云会使用密钥对请求体内容进行签名计算，并在请求头的
                 "X-Authorization"字段中携带如下形式的键值对：

                 Signature=fd72d00543273d2f7b0e8a6ac7860379c2506376474fae831587bf014a70d
                 05d
                 开发者可自行计算得到回调请求体的签名，比对X-Authorization中的签名是否一
                 致来判断回调请求合法性。签名计算可参考1.4.8.6示例代码

回复参数

error_code       错误码，0代表成功，其他值参考常用错误码说明
int
使用限制             无
                 设置回调开启、回调地址、加密密钥，用户托管/取消托管设备时会调用回调地
功能说明             址通知开发者

示例：

Request:
{

      "enableCallback": 1,
      "callbackAddress": "http://developer.com.cn/tums/test"

}

Response:
{

      "error_code": 0
}
```
