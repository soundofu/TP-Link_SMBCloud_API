#### 1.4.22.3 设备托管

##### 1.4.22.3.1 使用说明

```text
      当开发者有很多下游客户，且设备已接入下游客户的商云账号时，可不改变设备的账号归属，
通过“设备托管”功能将设备托管给开发者进行二次开发。

      整体使用流程与错误!未找到引用源。设备托管使用说明一致，仅国标设备与 TP-LINK 设备的
调用参数不同。
```

##### 1.4.22.5.2 推送消息体定义

```text
   国标设备订阅消息后推送的消息数据格式如下：

字段名             类型                                  备注

deviceGbId      string                              【必填】设备的 20 位国标设备 ID

sipServerId     string                              【选填】国标设备接入的 SIP 服务器 id，仅托管
                                                    设备有此字段

deviceName      string                              【必填】设备名称（别名）。

msgId           string                              【选填】消息的唯一标识，由消息源端保证唯一
                                                    性。若监听的消息未携带，可用 UUID 生成。

time            string                              【必填】消息产生时的 UTC 时间戳，消息如果

                                                    重复发送，该时间保持不变。单位秒。

msgType         string                              【必填】消息类型，详细定义见 1.4.8.7

msgContentType  array<string>                       【必填】描述具体消息，详细定义见 1.4.8.8

       "msgType":"vmsDeviceAlarm",

       "msgContentType":["NVRHardDiskAbnormal"]

 }
```
