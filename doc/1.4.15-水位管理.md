名称          内容

Path        /vms/open/waterLevelManager/v1/getLatestWaterLevelData
请求参数
            【可选】设备的17位设备码，设备标签上或扫描设备二维码得到的字符串，取该字
qrCode      符串"TP*"的后17位字符，即第4位到第20位字符（从1开始计数）。例如：设备标签
string      或 扫 描 二 维 码 得 到 的 字 符 串 为 ： TP116E0091709B04C926B00 ， 这 里 取
            "16E0091709B04C926"。
mac         mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为准。
string      【可选】设备mac地址，格式如00-FF-00-17-00-18，字母大写并用"-"分隔
回复参数        mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为准。

error_code  错误码，0代表正常，其他值参考常用错误码说明
int

            waterRulerName  产生本条记录的水尺名称
