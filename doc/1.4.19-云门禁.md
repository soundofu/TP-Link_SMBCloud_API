### 1.4.19 云门禁

#### 1.4.19.1 门禁设备开门/关门

```text
名称         内容

Path       /ams/open/deviceManager/v1/operateDoor
请求参数
qrCode     【必选】门禁设备的17位设备码，设备标签上或扫描设备二维码得到的字符串，
string     取该字符串"TP*"的后17位字符，即第4位到第20位字符（从1开始计数）。例如：
           设备标签或扫描二维码得到的字符串为：TP116E0091709B04C926B00，这里取
mac        "16E0091709B04C926"。
string
           【可选】设备mac地址，格式如00-FF-00-17-00-18，字母大写并用"-"分隔
operation  mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为
int        准。
           【必选】操作，枚举类型
doorNum
            枚举值 含义

            0       关门

            1       开门

           【可选】门禁主机可选参数，选择开/关门的编号，从 0 开始计数。默认为 0

int         可通过 1.4.19.2 获取门禁设备拓展信息获取
回复参数
error_code  错误码，0代表正常，其他值参考常用错误码说明
int         1. 设备需是TP-LINK门禁设备
            2. 设备型应用和项目型应用均可调用
使用限制        3. 需要目标设备处于试用中或付费使用中状态方可调用
            门禁设备开门关门
功能说明

示例：
Request:

      {
            "operation": 1,
            "qrCode": "799E562C2D6E2FA30"

}
Response:
{

      "error_code": 0
}
```

#### 1.4.19.2 获取门禁设备拓展信息

```text
名称          内容

Path        /ams/open/deviceManager/v1/getAmsDeviceExtendInfo
请求参数
            【可选】设备的17位设备码，设备标签上或扫描设备二维码得到的字符串，取该
qrCode      字符串"TP*"的后17位字符，即第4位到第20位字符（从1开始计数）。例如：设备
string      标 签 或 扫 描 二 维 码 得 到 的 字 符 串 为 ： TP116E0091709B04C926B00 ， 这 里 取
            "16E0091709B04C926"。
mac         mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为
string      准。
            【可选】设备mac地址，格式如00-FF-00-17-00-18，字母大写并用"-"分隔
            mac与qrCode两者至少存在一个，否则返回参数错误。两者都传时，以qrCode为
            准。

回复参数        错误码，0代表正常，其他值参考常用错误码说明
error_code
int                           门禁主机的门禁信息列表

result      entranceInfoList  doorNum  门禁编号，从0开始
object      array<object>     int      门禁的名称
                              name
使用限制                          string
功能说明
            1. 设备型应用和项目型应用均可调用
            2. 需要目标设备处于试用中或付费使用中状态方可调用

            获取门禁设备的扩展信息

示例：

       "qrCode": "16E0091709B04C926"
 }

       "error_code": 0,
       "result":

             "entranceInfoList": [
             {

                   "name": "门 1",

 }
```
