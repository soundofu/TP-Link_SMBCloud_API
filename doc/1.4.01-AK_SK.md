#### 1.4.1.2 创建权限策略

```text
名称            内容
Path          /tums/open/credentialManager/v1/createPolicy
请求参数
policyName    【必选】策略名称，不能重复，长度限制：[1,64]
string
policyDesc    【必选】策略描述，长度限制：[1,512]
string
policyDetail  【必选】策略详情       【必选】策略语法版本，当前仅可用 1.0.0
object        version
              string
                             【必选】策略语句列表，长度限制：[1,10]
              statement                          传入 api 路径列表的效用，枚举值
              array<object>
                             effect         枚举值             含义
                             string         allow           允许调用

                                            deny            禁止调用

                             api            API 路径列表，Ant 路径模式。列表长度
                             array<string>  限制：[1,1000]，列表元素长度限制：[1,
                                            256]
                                            路径规则（Ant Path Style）：
                                            1. 所有 API 路径必须以 "/" 开头
                                            2. "*" 匹配单层路径段
                                            3. "**" 匹配多层路径段
                                            4. 特殊值说明：

                                                - "/**" : 表示匹配所有接口
                                            5. 不支持正则表达式
                                            deny 优先级高于 allow，1. 命中 deny →
                                            直接拒绝；2. 未命中 deny → 检查
                                            allow；3. 命中 allow → 放行

回复参数        错误码，0 代表正常，其他值参考常用错误码说明。
error_code
int         policyId               策略 id
result
object      string
使用限制
            1. 设备型应用和项目型应用均可调用。
功能描述        2. 仅可以使用应用的长期 AK/SK 调用
            3. 最多创建 10000 个策略
            创建权限策略，可以使用自定义的权限策略限制临时 AK/SK 可以调用的接口范
            围

示例：
Request:
{

         "policyName": "自定义策略",
         "policyDesc": "自定义策略",
         "policyDetail": {

            "version": "1.0.0",
            "statement": [

               {
                  "effect": "allow",
                  "api": [
                     "/tums/open/deviceManager/v1/bindDeviceByQrCode",
                     "/tums/open/deviceConfig/v1/**"
                  ]

               }
            ]
   }
}

Response:
{

      "result": {
            "policyId": "2562515"

      },
      "error_code": 0
}
```
