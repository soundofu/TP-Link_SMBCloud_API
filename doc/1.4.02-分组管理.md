### 1.4.2 分组管理

#### 1.4.2.1 添加分组

```text
名称            内容

Path          /tums/open/resource/v1/addRegion
请求参数          【必选】分组名称，长度限制：[1,32]
regionName    【必选】父分组 id，无父分组时传"0"
string
parentId
string
回复参数

error_code    错误码，0代表正常，其他值参考常用错误码说明
int

              regionId     分组id
              string

result        regionLevel  分组的层级，取值范围：[1,8]
object        int

              order        分组在此层中的顺序
              int

使用限制          仅项目型应用可以调用

功能说明          1. 添加项目内分组
              2. 分组最多有 8 层嵌套

示例：

Request:
{

      "regionName":"root1.2",
      "parentId":" 574673185061091310"
}

Response:
{

      "result": {
            "regionId": "574673185061091311",
            "regionLevel": 2,
            "order": 2

      },
      "error_code": 0
}
```
